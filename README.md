# Why not? — электронное меню

Сайт меню бара «Why not?» для гостей (QR-код на столах).
Адрес: https://vinfastrentalvn-cloud.github.io/whynot-menu/

- `index.html` — страница меню (языки, светлая/тёмная тема).
- `menu-data.js` — позиции и цены (собирается из данных приложения).
- `img/` — фото коктейлей и шотов.
