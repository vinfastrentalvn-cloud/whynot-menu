# Why not? — электронное меню

Сайт меню бара «Why not?» (travel bar · Mui Ne) для гостей, открывается по QR-коду.
Адрес: https://vinfastrentalvn-cloud.github.io/whynot-menu/

- `index.html` — страница меню: 8 языков, жёлто-чёрная и тёмная темы, мобильная и десктопная вёрстка.
- `menu-data.js` — позиции и цены (собирается из данных приложения, вручную не править).
- `origin-data.js` — страны происхождения и типы напитков (правится отдельно).
- `img/` — фото коктейлей и шотов, `img/bottles/` — фото бутылок.

Прежняя версия дизайна: ветка `v1-before-redesign`.
